# unitree_go2_hoehlenforscher

ROS 2 workspace for Unitree GO2 entrance detection from LiDAR point clouds.
The current focus is identifying passable cave-like entrances.

## Project Scope

This repository is a research/development workspace and currently covers:

- entrance detection from LiDAR point clouds
- decision logic based on detected entrance dimensions
- action interface for height adjustment decisions

## Current Validation Status

The entrance detection pipeline has been tested with cardboard cutouts.

## Important Limitation

Height adjustment execution is not fully implemented yet.
The `action_node` currently contains placeholder logic where the real GO2 body-height command flow must be added.

## Workspace Layout

```text
src/
  go2_msgs/
  go2_my_nodes_py/
```

## Requirements

- ROS 2 Humble (or compatible)
- `colcon`
- Python 3
- Unitree ROS 2 interface that provides `unitree_api/msg/Request`
- ROS 2 message packages used by the nodes:
  - `geometry_msgs`
  - `sensor_msgs`
  - `std_msgs`
  - `visualization_msgs`
- Python packages:
  - `numpy`
  - `scipy`

## Build

```bash
rosdep install --from-paths src --ignore-src -r -y
colcon build
```

Source the workspace after build:

```bash
source install/setup.bash
```

## Run (Recommended: RANSAC)

Launch the RANSAC-based detector:

```bash
ros2 launch go2_my_nodes_py hole_detection_ransac.launch.py
```

Run the action server:

```bash
ros2 run go2_my_nodes_py action_node
```

Run the entrance decision node:

```bash
ros2 run go2_my_nodes_py entrance_decision_node
```

## Main Interfaces

- subscribes to `/utlidar/cloud_deskewed`
- publishes entrance detections and RViz markers
- exposes/uses the `height_adjustment` action
- can send GO2 movement requests via `/api/sport/request` (depending on node and integration)

## Notes

- `build/`, `install/`, and `log/` are generated by `colcon` and should not be committed.
- Test robot motion only with proper safety precautions and emergency stop readiness.
