# unitree_go2_hoehlenforscher

ROS 2 workspace for controlling a Unitree GO2 and detecting passable cave entrances from LiDAR point clouds.

License: Apache-2.0

## Status

Experimental research code. The workspace currently contains:

- `go2_msgs`: custom ROS 2 messages and actions for entrance evaluation and height adjustment.
- `go2_my_nodes_py`: Python nodes for entrance detection, decision making, and GO2 motion commands.

This repository is intended as a development workspace, not a polished SDK.

## Features

- custom `Entrance` message and `HeightAdjustment` action
- point-cloud-based entrance detection with multiple approaches
- action-based decision pipeline for passable vs. non-passable entrances
- Unitree GO2 Sport API integration via `/api/sport/request`
- RViz configuration and launch file for voxel-grid detection

## Requirements

- ROS 2 Humble or compatible setup
- `colcon`
- Python 3
- Unitree ROS 2 interface that provides `unitree_api/msg/Request`
- a GO2-compatible environment if you want to execute real robot motion commands
- ROS 2 message packages used by the nodes, including:
  - `geometry_msgs`
  - `sensor_msgs`
  - `std_msgs`
  - `visualization_msgs`

Depending on which detector you run, you may also need Python packages such as:

- `numpy`
- `scipy`

For a clean ROS 2 setup, install system dependencies with `rosdep` before building.
The Unitree API dependency may need to be installed manually depending on how you integrate the vendor SDK.

## Build

Clone the repository into a ROS 2 workspace and build it with `colcon`:

```bash
rosdep install --from-paths src --ignore-src -r -y
colcon build
```

Then source the generated environment:

```bash
source install/setup.bash
```

On macOS or zsh-based shells, use the matching setup script generated by ROS 2 for your environment.

## Run

Launch the clean entrance detection node:

```bash
ros2 launch go2_my_nodes_py hole_detection_clean.launch.py
```

Run the action server for height adjustment decisions:

```bash
ros2 run go2_my_nodes_py action_node
```

Run the entrance decision node:

```bash
ros2 run go2_my_nodes_py entrance_decision_node
```

## Topics and Interfaces

Current code references these main interfaces:

- subscribes to `/utlidar/cloud_deskewed`
- publishes entrance detections and visualization markers
- uses `/api/sport/request` for GO2 motion commands
- exposes the `height_adjustment` action

## Important Note About `install/`, `build/`, and `log/`

These directories are generated by `colcon build` and should not be committed to Git.

- `build/`: intermediate build artifacts
- `install/`: generated runtime environment and installed packages for the local workspace
- `log/`: build logs

They are required locally after a build, but they are not source code and should not live in the repository.

## Safety

This repository can send movement commands to a physical robot. Test with adequate clearance, supervision, and an emergency stop procedure.
